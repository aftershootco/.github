# Welcome to Aftershoot's GitHub 👋

Welcome to Aftershoot's GitHub profile! We are a cutting-edge platform leveraging AI to transform photography workflows by automating tedious tasks like culling, editing, and retouching. Our mission is to empower photographers to focus on creativity while we handle the rest.

## About Aftershoot 🦄

At Aftershoot, we believe in using state-of-the-art technology to simplify photography post-production. Our flagship products include:

- **Aftershoot Selects**: AI-powered photo culling for faster and smarter selections.
- **Aftershoot Edits**: A comprehensive solution combining culling, personalized AI editing, and more.
- **AI Retouching (Coming Soon)**: Fully automated, high-quality photo retouching to save photographers even more time.

## Tech Stack 🧑🏻‍💻👩🏻‍💻

Our platform is built on a modern, scalable, and efficient technology stack designed to deliver high performance and a seamless user experience. Here's an overview of our key technologies:

### Desktop app 🖥️
- **Programming Languages**: Rust, Typescript, Golang, C++
- **Databases**: PostgreSQL, SQLite
- **Infrastructure**: GCP
- **Frameworks & Libraries**: React.js, ElectronJs

### AI & ML 🐍
- **Frameworks**: TensorFlow, PyTorch
- **Key Areas**: Computer Vision, Recommendation Systems, Diffussion models
